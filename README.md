# EL PACTO

### A persistent-world tabletop-style campaign built on a private World of Warcraft server

A private World of Warcraft 3.3.5a server turned into a *Dungeons & Dragons*-style experience: a closed group of players lives a chaptered campaign in a world that **remembers everything they do** — and where your character isn't picked from a menu, it's **discovered**.

On first login the player meets the **Scribe of the Pact**, an NPC who asks six questions inside the game. The answers determine their **lineage** — vampire, lycanthrope, necromancer, oath-bound, light-touched, storm-child or giant-blooded — each with a real mechanical advantage and a real cost. Then they choose a class, write their history, and confess a secret only the system will know… and that the campaign will use.

> The vampire drains life on kill and grows stronger in darkness, but the sun burns 3% of their health every 30 seconds. Every pact has a price.

---

## Core ideas

**🕐 World Time** — The server runs its own accelerated clock: a full in-world day passes every 2.5 real hours, with announced sunrises and sunsets and a 28-day lunar cycle. Every system reads this clock: nocturnal lineages wake, the lamplighter child lights the village lanterns, and in the first campaign chapter the victory condition of a siege is literally **survive until dawn**.

**🎭 Nine-ability classes** — Characters don't play WoW's classes with their forty buttons. Each Pact class is a short, memorable kit: real spells, chat commands with animation (`#swear`, `#here`, `#wall`), passives, and one defining drawback. The Bulwark who swears to protect an ally absorbs their punishment… and is dishonored if they flee.

**🧠 A world with memory** — Every notable event is written to a persistent chronicle. NPCs greet players by their deeds, a village drunk babbles real facts from the server's history, and each chapter's decisions branch the chapters that follow. Villagers turned during the night of the siege reappear weeks later, by name, in the forest.

**🎬 Campaigns as native quests** — Chapters are played through the client's own quest system — exclamation marks, trackable objectives — while a scene engine fires on-screen narration, custom music, weather and encounters from triggers: reaching a place, the world clock, a choice made in a menu.

## Technical overview

| Layer | Technology |
|---|---|
| Server | AzerothCore (open-source C++) in Docker on Apple Silicon, **unmodified** |
| Game logic | **9 custom Lua modules** (mod-ale) — self-contained, each with its own on/off switch |
| Content & balance | 100% **data-driven** in MySQL (custom `pacto` schema): adding content is an INSERT |
| Client | Stock WoW 3.3.5a + an **optional MPQ patch** generated by custom tooling |
| Tooling | A `Spell.dbc` editor (binary WDBC format) and an MPQ packer, both in **Python** — they rename spells and rewrite tooltips using the client's native macros |
| Distribution | One-click launcher that switches between servers, installs or removes the patch, and clears the client cache |

### Design principles

- **Zero custom C++.** The engine is never forked, so upstream updates never break the project.
- **Only assets that already exist in the client.** No new models, no new maps.
- **Every module fails silently** without taking the others down.
- **No balance number lives in code.** All of it is data.

### Things worth a look if you're reading this as an engineer

- **`tools/`** — Parsing and rewriting an undocumented legacy binary format (WDBC), then repackaging the client archive. Reverse-engineered from the format itself.
- **`lua_scripts/`** — Nine independent modules coordinating through one shared clock, with fault isolation between them.
- **`sql/`** — The `pacto` schema. Content, balance and narrative branching all live here, which is what makes "add a chapter" a data change rather than a deploy.

## The modules (`lua_scripts/`)

| Module | What it does |
|---|---|
| `0_pacto_lib.lua` | Shared library: cached config, the chronicle, world announcements |
| `worldclock.lua` | **World Time**: the accelerated in-world clock, announced dawn/dusk, lunar cycle — every system reads this clock, never the real one |
| `escribano.lua` | **In-game character creation**: a six-question gossip test → the lineage emerges from the answers → class choice → history and secret dictated through chat |
| `lineages.lua` | Engine for the 7 lineages (traits on pulse/kill/login, all parameters in SQL) |
| `classes.lua` | Pact classes: short ability kits over an emptied chassis (animated commands like `#swear`, `#here`, `#wall`) |
| `outfits.lua` | Iconic per-class outfits (server-side transmogrification, no helmet — the face belongs to the character) |
| `pueblo.lua` | Darkshire breathes: data-driven NPC banter |
| `qol.lua` | Quality of life (tutorial popups silenced forever) |

## Design docs (`design/`)

Full specs live alongside the code: the seven lineages with their numbers, the five classes and their kits, the Darkshire NPC census, the chapter template the scene engine executes, and the first campaign chapter (*"The Last Night of the Red Raven"* — a night siege where the victory condition is the world clock reaching dawn).

## Running the server

1. Clone AzerothCore (commit `5239460`) with [mod-ale](https://github.com/azerothcore/mod-ale) into `azerothcore-wotlk/`.
2. Copy `config/env.pacto` → `azerothcore-wotlk/.env` and `config/docker-compose.override.yml` (replace `<TAILSCALE_IP>` with your own network address).
3. `docker compose up -d` (first run compiles from source on arm64), then apply `sql/*.sql` in order — **always with `--default-character-set=utf8mb4`**.
4. Lua scripts are bind-mounted and hot-reload with `reload ale` over SOAP. Daily backups: `tools/backup-pacto.sh`.
